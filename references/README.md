# References

This folder preserves original external material.

Reference files may include downloaded papers, arXiv sources, original code,
licenses, and provenance notes. They are not cleaned Econlib modules.

- `lean4/` stores original Lean 4 material.
- `lean3/` stores original Lean 3 material that may require porting.
- `isabellehol/` is reserved for original Isabelle/HOL material.
- `coqrocq/` is reserved for original Coq/Rocq material.
- `mizar/` is reserved for original Mizar material.
- `other/` is reserved for original formal-methods material outside the named systems.

Only create topic subfolders inside these language folders after source
artifacts have actually been collected.
