# Decision Theory / Utility Theory

Decision theory is the first natural Lean 4 implementation target because it
connects preferences, finite outcomes, lotteries, utility functions, expected
utility, and vNM-style representation results.

Mapped sources:

- vNM Utility Theorem in Lean 4
- vNM Utility Theorem in Isabelle/HOL

Near-term Econlib work should start below the full theorem: finite lotteries,
expected utility, mixture operations, and positive affine transformations.
