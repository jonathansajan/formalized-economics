# Documentation

This folder is the human-readable map for the project.

- `topics/` groups sources by economics area.
- `sources/` records one mapped source or project per file.
- `structure.md` explains the repository layout.
- `roadmap.md` describes the staged path from map to Lean 4 library.

The documentation may discuss Lean, Isabelle/HOL, Coq/Rocq, Mizar, and other
systems. Only cleaned Lean 4-facing work should go under `Econlib/`.
